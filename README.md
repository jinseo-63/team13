## 1. 프로젝트 소개

부산대학교(부산광역시 금정구) 인근에서 자취방을 구하는 대학생과 1인 가구를 위해, **국토교통부 전월세 실거래가 데이터**와 **카카오 로컬 API 생활 인프라 데이터**를 결합하여 입지 조건과 가성비를 한눈에 비교할 수 있도록 제작한 Streamlit 기반 데이터 분석 웹 애플리케이션입니다.

### 주요 기능
* **맞춤형 조건 필터링 및 요약 지표(KPI)**: 희망 주거 형태(전체/전세/월세), 보증금·월세 예산 범위, 필수 인프라(편의점, 지하철역, 코인세탁소, 마트)를 선택하면 조건에 부합하는 매물 수, 평균 보증금, 평균 월세를 실시간으로 산출합니다.
* **인프라 최단 도보 거리 및 접근성 점수 계산**: 하버사인(Haversine) 공식과 도보 우회 계수(1.3)를 적용해 각 매물에서 4대 생활 인프라까지의 최단 도보 거리(m)와 100점 만점 기준의 인프라 접근성 점수를 계산합니다.
* **인터랙티브 지도 시각화 (Folium)**: 원룸 실거래가 분포 히트맵(HeatMap) 위에 선택한 생활 인프라 아이콘 마커를 오버레이하여 공간적 분포를 직관적으로 확인할 수 있습니다.
* **통계적 상관관계 및 가성비 구역 순위 분석**: 월세·보증금과 인프라 도보 거리 간의 피어슨 상관계수(`r`) 및 유의확률(`p-value`)을 검증하고, 동(구역)별 평균 월세 대비 인프라 접근성 점수를 비교한 가성비 순위표를 제공합니다.
* **보고서용 시각화 차트 3종 및 데이터 다운로드**:
  1. 구역(동)별 평균 월세 vs 인프라 접근성 점수 이중축 비교 차트
  2. 월세와 인프라 도보 거리의 상관관계 산점도 (회귀 추세선 및 상관계수 표시)
  3. 선택 조건의 보증금 및 월세 분포 박스플롯·히스토그램
  * 필터링된 최종 원룸 매물 목록은 CSV 파일로 바로 다운로드할 수 있습니다.
